# Үйлөнүү тойго чакыруу — Бактыяр & Диана

Одностраничный сайт-приглашение на кыргызском языке: обложка с кнопкой
«Чакырууну ачуу», фоновая музыка, падающие лепестки, анимированный главный
экран, разделы «Чакыруу», «Той салтанаты» (дата + календарь), «Тойго чейин»
(обратный отсчёт), «Дарегибиз» (карта + 2GIS), «Той ээлери», «Эскертүү» и
«Суроо» — форма ответа гостей.

Без сборки и зависимостей: чистые HTML / CSS / JS.

## Две версии оформления

| Версия | Где | Стиль |
|--------|-----|-------|
| 1 — «Классика» | `index.html` (корень сайта) | зелёный конверт с сургучной печатью на обложке, переключатель РУ/КЫ, фото пары на главном экране (`heroImage`), лепестки, побуквенное появление имён |
| 2 — «Карта» | `v2/index.html` (адрес `…/v2/`) | пергамент, всё прорисовывается линиями: горы Ала-Тоо, компас, юрта, пунктирный маршрут с метками по мере прокрутки, имена «пишутся» штрихом |

Обе версии читают один и тот же `config.js` и одну музыку. Чтобы сделать
версию 2 основной, поменяйте местами содержимое корня и папки `v2/`
(в `v2/index.html` исправьте пути `../config.js` → `config.js`).

## Как поменять тексты

Все имена, дата, адрес, телефон и тексты — в одном файле **`config.js`**.
Отредактируйте значения, сохраните, запушьте в `main` — сайт обновится сам.

| Поле | Что это |
|------|---------|
| `groom`, `bride`, `brideGenitive` | имена жениха и невесты; `brideGenitive` — форма «кимдин» (Диана → Диананын) |
| `hostFather`, `hostMother` | той ээлери (родители) |
| `date`, `timeStart`, `timeEnd` | дата `ГГГГ-ММ-ДД`, начало и конец тоя |
| `region`, `venueName`, `venueAddress` | адрес |
| `routeUrl`, `mapQuery` | ссылка «Картадан кароо» (2GIS) и адрес для встроенной карты |
| `googleScriptUrl` | URL Google Apps Script — ответы гостей попадут в Google Таблицу |
| `whatsapp` | номер WhatsApp (только цифры с кодом страны); используется, если `googleScriptUrl` пуст |
| `inviteTitle`, `inviteText`, `notes`, `closingText` | тексты; в них работают подстановки `{groom}`, `{bride}`, `{brideGenitive}`, `{timeEnd}` |
| `music` | путь к музыке — замените `assets/music.mp3` на свою мелодию |
| `heroImage` | фото пары или места для главного экрана версии 1, например `assets/hero.jpg` |
| `ru` | русские варианты текстов для переключателя РУ/КЫ (версия 1) |

## Персональные ссылки

Добавьте к адресу `?g=Имя`, и на главном экране появится обращение «Урматтуу Имя!»,
а имя подставится в форму ответа. Пример: `https://magamed56.github.io/ernis_toy/?g=Асан%20жана%20Айгүл`.
При отправке ссылки в WhatsApp показывается превью `assets/og.png` с именами и датой.

## Календарь

Кнопка «Календарга кошуу» на iPhone открывает файл `assets/toy.ics` (системный календарь),
на Android и компьютере — Google Календарь. При смене даты пересоздайте `assets/toy.ics`.

## Ответы гостей в Telegram (самый простой способ)

Ответы приходят сообщением в Telegram сами, гостю ничего отправлять не нужно.

1. В Telegram откройте **@BotFather** → `/newbot` → придумайте имя → скопируйте **token** (вида `123456:ABC-…`).
2. Найдите своего бота по имени и нажмите **Start**, напишите ему любое слово.
3. Откройте в браузере `https://api.telegram.org/bot<TOKEN>/getUpdates` и найдите число `"id"` внутри `"chat"` — это **chatId**.
4. Впишите оба значения в `config.js` → `telegram: { token: "…", chatId: "…" }`.

Если хотите получать ответы вдвоём, создайте группу, добавьте бота и используйте id группы (отрицательное число).

## Ответы гостей в Google Таблицу

1. Создайте Google Таблицу → Расширения → Apps Script.
2. Вставьте содержимое `google-apps-script.js`, сохраните.
3. Развернуть → Новое развёртывание → Веб-приложение, «Выполнять от имени: Я», «Доступ: Все».
4. Скопируйте URL и вставьте в `config.js` → `googleScriptUrl`.

Пока URL не задан, ответ гостя открывается готовым сообщением в WhatsApp.

## Публикация на GitHub Pages

Сайт живёт по адресу https://magamed56.github.io/ernis_toy/ (версия 2: https://magamed56.github.io/ernis_toy/v2/).

GitHub Pages раздаёт ветку `gh-pages`. Workflow `.github/workflows/deploy.yml`
при каждом пуше в `main` копирует её в `gh-pages`, поэтому достаточно править
файлы в `main`: через 1–2 минуты сайт обновится.
